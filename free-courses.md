## Course 1: Study Skills Bootcamp: Focus and Memory

- Slug: study-skills-bootcamp
- Price: 0
- Free: true
- Category: Study Skills
- Short description:
  Build focus, memory, and study routines with practical exercises you can use today.

### Section 1: Foundations of Focus

Lesson 1: Focus reset in 15 minutes
- Duration: 10
- Preview: true
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4
- Content:
  Start by clearing your desk and removing all notifications from your phone and browser. The goal is to reduce cues that pull you away from deep work. Set a timer for 15 minutes and commit to a single task with a clear outcome.

  Use a simple rule: if a thought is not needed to complete the task, write it on a scratch note and return to the work. This creates a parking lot for distractions so you do not lose them, but also do not chase them. Repeat this for two short sessions per day.

Lesson 2: Build a distraction map
- Duration: 12
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ElephantsDream.mp4
- Content:
  Create a list of your top five distractions. For each one, write the trigger, the usual time it appears, and a simple replacement action. This turns a vague problem into a concrete plan.

  Example: If you reach for your phone when a task feels boring, replace that moment with a 30 second stretch or a glass of water. The replacement does not need to be perfect. It only needs to be easy and consistent.

### Section 2: Memory That Sticks

Lesson 3: The 3 layer memory method
- Duration: 14
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerBlazes.mp4
- Content:
  Memory improves when you encode information with meaning, structure, and repetition. Start by summarizing the topic in your own words. Then create a simple outline that shows how ideas connect.

  Finally, schedule two short reviews: one after 24 hours and one after 7 days. Use active recall. Close your notes and write down what you remember. This is the fastest way to strengthen memory.

Lesson 4: Quick recall drills
- Duration: 9
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerJoyrides.mp4
- Content:
  Turn each topic into five short questions. Answer them from memory, then check your notes. Keep a score and track improvement over a week.

  If you miss a question, rewrite the answer in one sentence and practice it again the next day. Small, frequent drills create strong retention without long study hours.

### Section 3: Weekly Routine

Lesson 5: Build a 7 day study plan
- Duration: 11
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerEscapes.mp4
- Content:
  Choose two focus blocks per day: one for learning, one for practice. Assign a single topic to each block. Keep sessions short at first, then extend them by 5 minutes each week.

  Add a weekly review day where you reattempt key questions from the past six days. This builds a feedback loop and keeps progress visible.

Lesson 6: Track wins and adjust
- Duration: 8
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/Sintel.mp4
- Content:
  At the end of each week, write down three wins and one change you will make. Wins build confidence. Changes keep your plan realistic.

  If a session felt too long, shorten it. If a topic felt too easy, combine two topics in one block. The plan should evolve with you.

## Course 2: Web Design Basics: HTML, CSS, and Layout

- Slug: web-design-basics
- Price: 0
- Free: true
- Category: Web Development
- Short description:
  Learn the building blocks of clean web pages with practical HTML, CSS, and layout patterns.

### Section 1: HTML Essentials

Lesson 1: Page structure that scales
- Duration: 12
- Preview: true
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/TearsOfSteel.mp4
- Content:
  Start with a simple structure: header, main, and footer. Inside main, group content into sections. This makes your page easier to read and style.

  Use semantic tags like <header>, <section>, and <article> to describe meaning. This helps accessibility tools and also makes your CSS clearer.

Lesson 2: Images, links, and lists
- Duration: 10
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerFun.mp4
- Content:
  Use images with descriptive alt text so users and search engines understand your content. Links should explain where they go, not just say click here.

  Lists are perfect for features, steps, and resources. Build consistent spacing using CSS and keep lists short and scannable.

### Section 2: CSS Foundations

Lesson 3: Typography and spacing rules
- Duration: 14
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerJoyrides.mp4
- Content:
  Choose two font sizes for headings and two for body text. Keep line height between 1.4 and 1.6 for readability. Limit line length to about 60 characters.

  Use a spacing system like 4, 8, 12, 16, 24. Consistent spacing makes your page feel intentional and professional.

Lesson 4: Color and contrast basics
- Duration: 9
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerEscapes.mp4
- Content:
  Pick one primary color, one accent, and a set of neutrals. Apply contrast checks to ensure readability. If text feels weak, darken the color or increase the font weight.

  Use background tints for sections and cards instead of heavy borders. This keeps the UI clean while still separating content.

### Section 3: Layout Patterns

Lesson 5: Flexbox for simple layouts
- Duration: 12
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/Sintel.mp4
- Content:
  Flexbox is ideal for headers, navigation, and card grids. Use justify-content to control spacing and align-items to keep content balanced.

  Practice by building a hero section with a title on the left and an image on the right. Then switch to a stacked layout on mobile.

Lesson 6: Responsive grid and cards
- Duration: 11
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4
- Content:
  Use CSS grid for multi column layouts that adapt to screen size. Start with two columns on desktop and one column on mobile.

  Cards should have consistent padding, a light shadow, and a clear call to action. Keep all cards the same height to avoid messy grids.

## Course 3: Python Foundations for Data and Automation

- Slug: python-foundations
- Price: 0
- Free: true
- Category: Python
- Short description:
  Build confidence in Python basics, then automate tasks and analyze simple data sets.

### Section 1: Python Basics

Lesson 1: Variables and data types
- Duration: 13
- Preview: true
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ElephantsDream.mp4
- Content:
  Start with numbers, strings, and booleans. Practice by creating variables for a simple project like a study tracker or expense list.

  Use print statements to confirm your values. Then change values to see how Python updates variables in memory.

Lesson 2: Conditions and loops
- Duration: 15
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerBlazes.mp4
- Content:
  Learn if and else statements to control flow. Use for loops to repeat actions like processing a list of scores.

  A simple exercise: list five study tasks, then loop through them and mark each one complete. This teaches iteration and basic logic.

### Section 2: Functions and Files

Lesson 3: Functions that reuse logic
- Duration: 12
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerJoyrides.mp4
- Content:
  Functions keep your code clean and reusable. Start by writing a function that calculates average scores.

  Use parameters to pass data and return values to get results back. This pattern is the foundation for building larger programs.

Lesson 4: Read and write files
- Duration: 11
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerEscapes.mp4
- Content:
  Use the open function with read and write modes. Practice by saving a list of tasks to a text file and loading it later.

  Always close files or use the with statement so files are handled safely. This will also reduce errors in longer scripts.

### Section 3: Data and Automation

Lesson 5: Lists and dictionaries for data
- Duration: 12
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/Sintel.mp4
- Content:
  Lists store ordered data and dictionaries store key value pairs. Use a list of dictionaries to represent students and scores.

  Practice by calculating the highest score and the average score. This will prepare you for larger data sets later.

Lesson 6: Simple automation script
- Duration: 10
- Preview: false
- Video: https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/TearsOfSteel.mp4
- Content:
  Build a script that renames files or formats a report. Start small with a single folder, then expand to multiple files.

  Automation is about saving time. Keep your script readable and add clear print statements so you know what changed.
